## [1.0.0] - 2026-09-27

### Added

- Holographic brain background: ghostly silhouette, wireframe mesh, point cloud, cross sections, scan lines and reticle.
- Neural network frame around each note.
- Dark color scheme with lavender, blue and white accents, and a softer light mode.
- Glowing headings, links, tags, horizontal rules, code blocks and quotes.
- Graph view colors.
- Generator script `tools/build_theme.py`.
